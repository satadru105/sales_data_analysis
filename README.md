# Sales Data Analysis

## Project overview

This Week 3 project uses Python and Pandas to explore and clean transaction
data, calculate sales metrics, and generate a Markdown report with a product
revenue chart. The goal is to identify overall sales performance and the
products leading in revenue and quantity sold.

## Project structure

```text
Sales_Data_Analysis/
├── sales_analysis.py
├── sales_data.csv
├── analysis_report.md       # generated by the analysis
├── sales_by_product.svg     # generated visual
├── requirements.txt
├── README.md
└── tests/
    └── test_sales_analysis.py
```

## Setup and run

Requirements: Python 3.9 or newer and pip.

From PowerShell, open the project directory and run:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python sales_analysis.py
```

The script reads `sales_data.csv` from its own directory and writes
`analysis_report.md` and `sales_by_product.svg` alongside the script. The CSV
may label the price field `Price` or `Unit_Price`; both are supported.

## Analysis steps and technical details

1. Load the CSV with `pandas.read_csv` and check for the required
   `Product`, `Quantity`, and price columns.
2. Print the original dataset preview, dimensions, data types, and missing
   value counts.
3. Remove exact duplicate rows; trim product names and exclude missing names.
4. Convert quantity and price to numeric values. Exclude missing/non-numeric
   values, non-positive quantities, and negative prices.
5. Recalculate each row's `Total_Sales` as `Quantity * Unit_Price`; this
   intentionally replaces any inconsistent supplied total.
6. Use Pandas `sum`, `mean`, `min`, `max`, and `groupby` operations for the
   summary metrics and product rankings.
7. Write the results to a Markdown report and generate a dependency-free SVG
   horizontal bar chart using the standard library.

Revenue and average sale value are calculated from valid transaction rows.
The top product by revenue and the best-selling product by quantity are
reported separately because those rankings need not match.

## Testing and validation evidence

Run the automated end-to-end test from the project directory:

```powershell
python -m unittest discover -s tests -v
```

The test runs the script against a temporary CSV fixture. It checks support
for the `Price` header, duplicate and invalid-row handling, recalculated
revenue, the reported metrics, and generation of a valid SVG chart. It does not
modify the project's source CSV.

For a visual record of a manual run, capture the terminal showing
`python sales_analysis.py` and the generated report/chart, then save the image
under `screenshots/` before submitting. The SVG chart is generated
automatically; screenshots depend on the environment used for the run.
